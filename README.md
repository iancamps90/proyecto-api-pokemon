# 🎮 Pokédex Interactiva - Proyecto Pokémon

Una aplicación web moderna y completamente responsive que permite explorar el mundo Pokémon con funcionalidades avanzadas.

## 🌟 Características

### ✨ Funcionalidades Principales
- **🔍 Búsqueda y Filtros Avanzados**: Búsqueda en tiempo real, filtros por tipo, generación y estadísticas
- **🎮 Generador de Equipos**: Crea equipos balanceados con 4 estrategias diferentes
- **⚔️ Battle Simulator**: Simulador de batallas por turnos con cálculo de daño real
- **✨ Shiny Detector**: Detecta Pokémon Shiny con probabilidad 1/4096
- **❤️ Sistema de Favoritos**: Guarda tus Pokémon favoritos con localStorage
- **🌳 Árbol de Evoluciones**: Visualiza líneas evolutivas interactivas

### 🎨 Diseño y UX
- **📱 Completamente Responsive**: Optimizado para móvil, tablet y desktop
- **🌙 Modo Oscuro/Claro**: Cambio dinámico de tema
- **🎭 Animaciones Fluidas**: Efectos con Framer Motion
- **🎨 Colores Dinámicos**: Gradientes según tipo de Pokémon
- **💫 Efectos Glassmorphism**: Diseño moderno con efectos de cristal

### 🚀 Tecnologías
- **React 19** con Vite
- **Framer Motion** para animaciones
- **Chart.js** para gráficos
- **React Hot Toast** para notificaciones
- **CSS3** con efectos avanzados
- **PWA Ready**
